# Privacy Policy for KeyPocket

**Last Updated:** January 29, 2026

KeyPocket ("the Application") is designed with your privacy in mind.

1. **Data Collection**: The Application does not collect, transmit, or store any personal information on remote servers.
   We do not track your usage, nor do we use any analytics tools.
2. **Local Storage**: All data entered into the Application (including API Keys, Base URLs, and Model IDs) is stored
   locally on your device.
3. **Encryption**: Sensitive data (such as API Keys) is encrypted using Windows DPAPI (Data Protection API) before being
   saved to your local disk.
4. **Network Access**: The Application may access the internet solely for the purpose of checking for updates or
   connecting to the AI services you have configured. No personal data is sent to the developers of KeyPocket.

By using the Application, you agree to the terms of this Privacy Policy.
