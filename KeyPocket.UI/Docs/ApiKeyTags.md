# API Key 标签说明

KeyPocket 支持为每个 API Key 设置标签（Tag）。当标签中包含特定的关键字时，系统会自动应用预设的配色方案。

## 标签配色方案

系统会识别标签中的关键字并显示对应颜色（支持中英文）：

| 颜色     | 匹配关键字                            | 建议用途      |
|:-------|:---------------------------------|:----------|
| **蓝色** | `开发`, `测试`, `dev`, `test`        | 开发或测试环境   |
| **绿色** | `正式`, `生产`, `prod`, `production` | 生产环境      |
| **紫色** | `免费`, `试用`, `free`, `trial`      | 免费或试用 Key |
| **黄色** | `付费`, `收费`, `paid`, `premium`    | 付费或高级 Key |
| **橙色** | `临时`, `暂存`, `temp`, `staging`    | 短期临时 Key  |
| **灰色** | `备份`, `bak`, `backup`            | 冗余备份      |

## 使用说明

1. **设置方法**：在编辑 API Key 时，在“标签”字段输入文字。
2. **匹配规则**：标签内容只需包含上述关键字即可触发配色。例如 `dev-key` 会显示为蓝色。
3. **默认颜色**：如果输入的标签不包含任何预设关键字，系统将统一显示为**灰色**。
4. **主题适配**：标签颜色会随系统主题（亮色/暗色）自动调整显示亮度。
