# Changelog

## v1.0.3

### Added

- Refactored the Models and Keys pages with richer functionality.
- Improved the Provider Settings page layout.
- Global search now covers providers, models, and API key tags, with quick access to crash logs and the icon mapping file.
- Added CSV bulk import for models.
- Added model icon mapping and preset icon resources for clearer identification.
- Added window material options (Mica, Mica Alt, Acrylic, None).
- Added support for multiple tags per model (Text, File, Image, Audio, Video, Embeddings, Favorite, Deprecated).
